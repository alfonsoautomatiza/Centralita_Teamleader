# Visión general / Overview

## *Bienvenido a la documentación de Centralita IA Teamleader*

La integración de Teamleader le aporta mayores beneficios en sus comunicaciones porque le permite mejorar la gestión del tiempo y de los recursos. Esta integración de la centralita con el CRM TEAMLEADER destaca por la marcación de un solo clic al lanzar las llamadas, el registro automático con la información detallada de las llamadas, horarios y mucho más, lo que garantiza que tenga todos los datos de los clientes a mano y unas comunicaciones más efectivas. Apertura automática de la ficha de Teamleader que contiene el número entrante o saliente, y consulta de la base de datos de empresas con relleno de datos comerciales de forma rápida y sencilla.

---

## *Welcome to Centralita IA Teamleader documentation*

The integration of Teamleader brings you greater benefits in your communications because it allows you to improve time and resource management. This integration of the switchboard with the TEAMLEADER CRM features one-click dialing when launching calls, automatic logging of call details, times and more, ensuring you have all customer data at your fingertips and more effective communications. Automatic opening of the Teamleader card containing the incoming or outgoing number, plus quick and easy consultation of the company database with commercial data filled in.

# Novedades / What's new

## Versión 0.1.1 — 17/08/2026 (primera versión pública / first public release)

- **Nuevo canal oficial de distribución**: Centralita IA Teamleader se distribuye ahora desde `alfonsoautomatiza/Centralita_Teamleader`, con instalador oficial para Windows.
- **Infraestructura de actualizaciones firmadas**: las próximas versiones se publicarán con manifiestos firmados digitalmente, garantizando que solo se distribuyan versiones oficiales verificables.
- **Mayor estabilidad con tareas simultáneas**: se han corregido bloqueos y posibles incoherencias de datos cuando varias tareas (llamadas, registros) se procesan a la vez.
- **Seguridad reforzada**: token de seguridad para el webhook de Netelip, servidor interno limitado al propio equipo y credenciales fuera del repositorio.

--------
**English:**

- **New official distribution channel**: Centralita IA Teamleader is now distributed from `alfonsoautomatiza/Centralita_Teamleader`, with an official Windows installer.
- **Signed update infrastructure**: upcoming versions will be published with digitally signed manifests, guaranteeing that only official, verifiable releases are distributed.
- **More stable with simultaneous tasks**: fixed deadlocks and potential data inconsistencies when several tasks (calls, records) are processed at the same time.
- **Hardened security**: security token for the Netelip webhook, internal server bound to the local machine, and credentials kept out of the repository.

Detalles completos / Full details: [Novedades de la versión 0.1.1](https://alfonsoautomatiza.github.io/Centralita_Teamleader/updates/novedades-v0.1.1/)

# Instalación / Installation

- Descargue e instale la última versión desde [Releases](https://github.com/alfonsoautomatiza/Centralita_Teamleader/releases/latest).
- Instale y empareje el equipo Windows con la [App Call Remoto](https://alfonsoautomatiza.github.io/Centralita_Teamleader/es/castellano/App-Call-remoto/).
- Obtenga credenciales válidas para el [API de Teamleader](https://alfonsoautomatiza.github.io/Centralita_Teamleader/es/castellano/api-teamleader/).
- Rellene el [formulario de registro](https://forms.office.com/r/5k9k54cugV).
