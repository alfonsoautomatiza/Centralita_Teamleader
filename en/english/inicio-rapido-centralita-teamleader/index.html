    Quick Setup

    🚀 Quick Start - Teamleader PBX¶

    This guide will take you step-by-step through the installation and initial configuration of Teamleader PBX. In less than 10 minutes, you'll have the system running and ready to optimize your calls.

    📋 Prerequisites¶

    Before you begin, make sure you meet the following requirements:

    Operating System¶

    • Windows 10 or higher (Windows 11 recommended)
    • Disk space: Minimum 50 MB
    • RAM: Minimum 2 GB (4 GB recommended)
    • Internet connection: For API integration

    Required Accounts¶

    • Active Teamleader Focus account
    • Teamleader API credentials (see step 2)

    Step 1: Download and Install¶

    1.1 Download the Application¶

    Free Download

    Download the latest version of Teamleader PBX:

    📥 Download Setup_Centralita_IA_Teamleader.zip

    (Approximate size: ~15 MB)

    1.2 Install¶

    1. Unzip the file .zip in a folder of your choice
    2. Recommended: C:\Program Files\CentralitaIA\

    3. Avoid folders with spaces or special characters

    4. Run the installer

    5. Double click on Setup_Centralita_IA_Teamleader.exe

    6. Follow the installation wizard steps

    7. Finish installation

    8. Check "Run application" when finished
    9. Click on "Finish"

    1.3 Verify Installation¶

    After installation, you should see the PBX icon in the system tray (bottom right corner):

    ✅ Installation Completed

    If you see the icon in the system tray, the installation has been completed successfully.

    Step 2: Configure Teamleader API¶

    ⚠️ Required

    Without Teamleader API credentials, the application will not be able to sync contacts or create notes automatically.

    2.1 Obtain OAuth2 Credentials¶

    1. Access Teamleader Marketplace
    2. Visit: https://marketplace.focus.teamleader.eu/es/es/gestion

    3. Log in with your Teamleader account

    4. Create a new integration

    5. Click on "+ New integration"

    6. Fill in the fields:

      • Name: Teamleader PBX
      • Description: Automatic telephony integration
      • Application type: Web application

    7. Configure Redirect URIs

    8. In "Validate Redirect URIs" add exactly: 

      http://127.0.0.1:5000/callback

      Important

      Copy the URI exactly without spaces or additional characters.

    9. Configure OAuth Scopes

    10. Check the following permissions:
      • ✅ contacts:read
      • ✅ contacts:write
      • ✅ companies:read
      • ✅ companies:write
      • ✅ notes:write
      • ✅ deals:read
      • ✅ deals:write

    1. Save credentials

    2. Note down the following data:

      • Client ID: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
      • Client Secret: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

      Tip

      Save these credentials in a safe place. You'll need them in the next step.

    📹 Watch Video Tutorial

    If you prefer a visual guide, check out our video: API REGISTRATION FOR TEAMLEADER - YouTube

    2.2 Configure Credentials in PBX¶

    1. Open configuration
    2. Right click on the PBX icon in the system tray

    3. Select "Configuration"

    4. API Tab

    5. Navigate to the "API" tab

    6. Copy and paste the credentials:

      • Client ID: Paste the noted value
      • Client Secret: Paste the noted value

    7. Authorize the application

    8. Click on "Authorize Teamleader"
    9. A browser window will open
    10. Log in to Teamleader (if necessary)

    11. Click on "Authorize"

    12. Verify connection

    13. If everything is correct, you'll see a message: "✅ Successful connection with Teamleader"
    14. Tokens will be saved automatically

    ✅ API Configured

    Your PBX is now connected with Teamleader and can sync contacts automatically.

    Step 2.5: Configure OpenRouter (AI Transcription)¶

    ℹ️ What is OpenRouter?

    OpenRouter is a service that provides access to advanced Artificial Intelligence models (like Google Gemini) to automatically transcribe your phone calls and generate structured summaries with key points, decisions, and next steps.

    2.5.1 Why do you need OpenRouter?¶

    Without OpenRouter, PBX will not be able to: - ❌ Transcribe calls automatically - ❌ Generate structured summaries - ❌ Extract key points and decisions - ❌ Create detailed notes in Teamleader

    💡 AI Advantage

    With OpenRouter, each call is transcribed and summarized automatically, saving you hours of manual notes and ensuring no important detail is missed.

    2.5.2 Obtain OpenRouter API Key¶

    1. Create account on OpenRouter
    2. Visit: https://openrouter.ai/
    3. Click on "Sign Up" or "Register"

    4. Fill in your details (name, email, password)

    5. Verify email

    6. Check your inbox

    7. Click on the verification link

    8. Obtain API Key

    9. Log in to OpenRouter
    10. Navigate to "Settings" → "API Keys"
    11. Click on "Create new key"

    12. Copy the generated API Key

      ⛔ Save your API Key securely

      The API Key is like a password. Do not share it with anyone.

    2.5.3 Configure OpenRouter in PBX¶

    1. Open configuration
    2. Right click on the PBX icon

    3. Select "Configuration"

    4. Artificial Intelligence Tab

    5. Navigate to the "AI" or "Artificial Intelligence" tab

    6. Configure API Key

    7. Paste the OpenRouter API Key

    8. Select the model: google/gemini-2.5-flash-lite (recommended)

    9. Customize prompt (optional)

    10. You can customize the AI instructions

    11. For example: "Transcribe the call and focus on decisions made and next steps"

    12. Save configuration

    13. Click on "Save"
    14. You'll see: "✅ OpenRouter configured correctly"

    ✅ AI Configured

    Your PBX will now automatically transcribe all calls with artificial intelligence.

    2.5.4 Available AI Models¶

    Model Quality Cost Speed Recommended for
    google/gemini-2.5-flash-lite High Low ⚡ Very fast ✅ Daily use (recommended)
    google/gemini-2.5-flash Very high Medium ⚡ Fast Important calls
    openai/gpt-4o Excellent High 🐌 Slow Critical meetings
    💰 OpenRouter Costs

    OpenRouter costs are based on consumption: - Gemini 2.5 Flash Lite: ~$0.07 per 1 million tokens - Average call (5 min): ~200-300 tokens - Cost per call: ~$0.02 - $0.03 (2-3 US cents) - 100 calls/month: ~$2-3

    You can set a monthly spending limit in OpenRouter to control costs.

    Step 3: Android-Windows Pairing (Optional)¶

    ℹ️ Optional - Requires Third-Party App

    This step is optional but recommended if you want automatic call detection from your Android phone.

    3.1 What is pairing?¶

    Pairing allows PBX to automatically detect incoming and outgoing calls from your Android phone, without manual intervention.

    Requirements: - Android device 6.0 or higher - JustRemotePhone app installed - Both devices on the same WiFi network

    3.2 Install Pairing App¶

    1. Download app
    2. Visit: https://www.justremotephone.com/v6.10/CallCenter.msi

    3. Download and install on your Windows

    4. Install Android app

    5. On your Android, search for "JustRemotePhone" on Google Play

    6. Install the app

    7. Pair devices

    8. Open the app on Windows
    9. Open the app on Android
    10. Follow the pairing steps (a code will be displayed)
    📖 Detailed Pairing Guide

    For step-by-step instructions with screenshots, see: App-Call-remote - Complete Guide

    3.3 Verify Pairing¶

    1. Make a test call
    2. Call from your Android to any number

    3. PBX should detect the call automatically

    4. Verify notification

    5. You should see a notification on Windows: "📞 Call detected: +34 XXX XXX XXX"
    6. The Teamleader file should open automatically

    ✅ Pairing Completed

    Your PBX now automatically detects calls from your Android.

    Step 4: Register License¶

    📝 Required for Full Use

    Registration is free and necessary to activate all features.

    4.1 Registration Form¶

    1. Open form

    2. Visit: https://forms.office.com/r/5k9k54cugV

    3. Fill in details

    4. Full name
    5. Company
    6. Email
    7. Number of licenses needed

    8. Use case

    9. Submit form

    10. Click on "Submit"
    11. You'll receive your license by email within 24-48 hours

    4.2 Activate License¶

    1. Open configuration
    2. Right click on the PBX icon

    3. Select "Configuration"

    4. License Tab

    5. Navigate to the "License" tab

    6. Paste the license key received by email

    7. Activate

    8. Click on "Activate license"
    9. You'll see a message: "✅ License activated correctly"

    ✅ Registration Completed

    Your PBX is fully registered and ready to use.

    ✅ Final Verification¶

    Installation Checklist¶

    Before you start using PBX, verify that all steps are completed:

    • Application installed (icon visible in system tray)
    • Teamleader API configured (OAuth2 credentials)
    • OpenRouter configured (API Key and AI model)
    • Android pairing completed (optional but recommended)
    • License registered and activated
    • Stable internet connection

    First Test Call¶

    1. Make a call
    2. Call a test number

    3. Or receive a call on your Android

    4. Verify behavior

    5. ✅ PBX detects the call
    6. ✅ Teamleader file opens
    7. ✅ Recording starts
    8. ✅ Note is created in Teamleader after hanging up

    🎉 Congratulations!

    Your Teamleader PBX is fully configured and ready to optimize your calls.
