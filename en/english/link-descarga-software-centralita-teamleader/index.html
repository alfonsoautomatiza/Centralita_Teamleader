    Yes, the download is 100% free. There are no hidden payments or mandatory subscriptions.

    Only optional costs: - OpenRouter: ~$0.02-0.03 per call (2-3 cents) - JustRemotePhone: ~€9.99 one-time payment (optional, only for Android detection)

    Can I install on multiple PCs?¶

    Yes, without limit. You can install on as many PCs as you need: - For personal use: No limit - For business use: Contact for multi-user licenses

    No. PBX updates automatically. You don't need to download a new version unless explicitly indicated.
