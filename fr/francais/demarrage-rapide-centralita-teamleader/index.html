    Configuration Rapide

    🚀 Démarrage Rapide - Centralite Teamleader¶

    Ce guide vous accompagnera étape par étape dans l'installation et la configuration initiale de Centralite Teamleader. En moins de 10 minutes, vous aurez le système opérationnel et prêt à optimiser vos appels.

    📋 Prérequis¶

    Avant de commencer, assurez-vous de respecter les conditions suivantes :

    Système d'Exploitation¶

    • Windows 10 ou supérieur (Windows 11 recommandé)
    • Espace disque : Minimum 50 MB
    • Mémoire RAM : Minimum 2 GB (4 GB recommandé)
    • Connexion internet : Pour l'intégration avec les APIs

    Comptes Requis¶

    • Compte Teamleader Focus actif
    • Identifiants API de Teamleader (voir étape 2)

    Étape 1 : Télécharger et Installer¶

    1.1 Télécharger l'Application¶

    Téléchargement Gratuit

    Téléchargez la dernière version de Centralite Teamleader :

    📥 Télécharger Setup_Centralita_IA_Teamleader.zip

    (Taille approximative : ~15 MB)

    1.2 Installer¶

    1. Décompresser le fichier .zip dans un dossier de votre choix
    2. Recommandé : C:\Program Files\CentralitaIA\

    3. Éviter les dossiers avec espaces ou caractères spéciaux

    4. Exécuter l'installateur

    5. Double clic sur Setup_Centralita_IA_Teamleader.exe

    6. Suivre les étapes de l'assistant d'installation

    7. Terminer l'installation

    8. Cocher "Exécuter l'application" à la fin
    9. Cliquer sur "Terminer"

    1.3 Vérifier l'Installation¶

    Après l'installation, vous devriez voir l'icône de Centralite dans la barre des tâches (coin inférieur droit) :

    ✅ Installation Terminée

    Si vous voyez l'icône dans la barre des tâches, l'installation s'est déroulée avec succès.

    Étape 2 : Configurer l'API Teamleader¶

    ⚠️ Requis

    Sans les identifiants API de Teamleader, l'application ne pourra pas synchroniser les contacts ni créer des notes automatiquement.

    2.1 Obtenir les Identifiants OAuth2¶

    1. Accéder au Marketplace Teamleader
    2. Visitez : https://marketplace.focus.teamleader.eu/es/es/gestion

    3. Connectez-vous avec votre compte Teamleader

    4. Créer une nouvelle intégration

    5. Cliquez sur "+ Nouvelle intégration"

    6. Remplissez les champs :

      • Nom : Centralite Teamleader
      • Description : Intégration de téléphonie automatique
      • Type d'application : Application web

    7. Configurer les URIs de redirection

    8. Dans "Valider les URIs de redirection" ajoutez exactement : 

      http://127.0.0.1:5000/callback

      Important

      Copiez l'URI exactement sans espaces ni caractères additionnels.

    9. Configurer les OAuth Scopes

    10. Cochez les permissions suivantes :
      • ✅ contacts:read
      • ✅ contacts:write
      • ✅ companies:read
      • ✅ companies:write
      • ✅ notes:write
      • ✅ deals:read
      • ✅ deals:write

    1. Enregistrer les identifiants

    2. Notez les données suivantes :

      • Client ID : xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
      • Client Secret : xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

      Conseil

      Gardez ces identifiants dans un endroit sûr. Vous en aurez besoin à l'étape suivante.

    📹 Voir le Tutoriel Vidéo

    Si vous préférez un guide visuel, consultez notre vidéo : ENREGISTREMENT API POUR TEAMLEADER - YouTube

    2.2 Configurer les Identifiants dans Centralite¶

    1. Ouvrir la configuration
    2. Clic droit sur l'icône de Centralite dans la barre des tâches

    3. Sélectionner "Configuration"

    4. Onglet API

    5. Naviguez vers l'onglet "API"

    6. Copiez et collez les identifiants :

      • Client ID : Collez la valeur notée
      • Client Secret : Collez la valeur notée

    7. Autoriser l'application

    8. Cliquez sur "Autoriser Teamleader"
    9. Une fenêtre de navigateur s'ouvrira
    10. Connectez-vous à Teamleader (si nécessaire)

    11. Cliquez sur "Autoriser"

    12. Vérifier la connexion

    13. Si tout est correct, vous verrez un message : "✅ Connexion réussie avec Teamleader"
    14. Les tokens seront sauvegardés automatiquement

    ✅ API Configurée

    Votre Centralite est maintenant connectée avec Teamleader et peut synchroniser les contacts automatiquement.

    Étape 2.5 : Configurer OpenRouter (Transcription avec IA)¶

    ℹ️ Qu'est-ce qu'OpenRouter ?

    OpenRouter est un service qui fournit l'accès à des modèles d'Intelligence Artificielle avancés (comme Google Gemini) pour transcrire automatiquement vos appels téléphoniques et générer des résumés structurés avec points clés, décisions et prochaines étapes.

    2.5.1 Pourquoi avez-vous besoin d'OpenRouter ?¶

    Sans OpenRouter, Centralite ne pourra PAS : - ❌ Transcrire les appels automatiquement - ❌ Générer des résumés structurés - ❌ Extraire les points clés et décisions - ❌ Créer des notes détaillées dans Teamleader

    💡 Avantage de l'IA

    Avec OpenRouter, chaque appel est transcrit et résumé automatiquement, vous faisant gagner des heures de notes manuelles et garantissant qu'aucun détail important ne soit oublié.

    2.5.2 Obtenir la Clé API d'OpenRouter¶

    1. Créer un compte sur OpenRouter
    2. Visitez : https://openrouter.ai/
    3. Cliquez sur "Sign Up" ou "S'inscrire"

    4. Remplissez vos données (nom, email, mot de passe)

    5. Vérifier l'email

    6. Vérifiez votre boîte de réception

    7. Cliquez sur le lien de vérification

    8. Obtenir la Clé API

    9. Connectez-vous à OpenRouter
    10. Naviguez vers "Settings" → "API Keys"
    11. Cliquez sur "Create new key"

    12. Copiez la Clé API générée

      ⛔ Sauvegardez votre Clé API en toute sécurité

      La Clé API est comme un mot de passe. Ne la partagez avec personne.

    2.5.3 Configurer OpenRouter dans Centralite¶

    1. Ouvrir la configuration
    2. Clic droit sur l'icône de Centralite

    3. Sélectionner "Configuration"

    4. Onglet Intelligence Artificielle

    5. Naviguez vers l'onglet "IA" ou "Intelligence Artificielle"

    6. Configurer la Clé API

    7. Collez la Clé API d'OpenRouter

    8. Sélectionnez le modèle : google/gemini-2.5-flash-lite (recommandé)

    9. Personnaliser le prompt (optionnel)

    10. Vous pouvez personnaliser les instructions pour l'IA

    11. Par exemple : "Transcrivez l'appel et concentrez-vous sur les décisions prises et les prochaines étapes"

    12. Enregistrer la configuration

    13. Cliquez sur "Enregistrer"
    14. Vous verrez : "✅ OpenRouter configuré correctement"

    ✅ IA Configurée

    Votre Centralite transcrira maintenant automatiquement tous les appels avec intelligence artificielle.

    2.5.4 Modèles d'IA Disponibles¶

    Modèle Qualité Coût Vitesse Recommandé pour
    google/gemini-2.5-flash-lite Élevée Faible ⚡ Très rapide ✅ Usage quotidien (recommandé)
    google/gemini-2.5-flash Très élevée Moyen ⚡ Rapide Appels importants
    openai/gpt-4o Excellent Élevé 🐌 Lent Réunions critiques
    💰 Coûts d'OpenRouter

    Les coûts d'OpenRouter sont basés sur la consommation : - Gemini 2.5 Flash Lite : ~$0.07 par 1 million de tokens - Appel moyen (5 min) : ~200-300 tokens - Coût par appel : ~$0.02 - $0.03 (2-3 cents de dollar) - 100 appels/mois : ~$2-3

    Vous pouvez définir une limite de dépense mensuelle sur OpenRouter pour contrôler les coûts.

    Étape 3 : Jumelage Android-Windows (Optionnel)¶

    ℹ️ Optionnel - Nécessite une Application Tiers

    Cette étape est optionnelle mais recommandée si vous souhaitez la détection automatique des appels depuis votre téléphone Android.

    3.1 Qu'est-ce que le jumelage ?¶

    Le jumelage permet à Centralite de détecter automatiquement les appels entrants et sortants depuis votre téléphone Android, sans intervention manuelle.

    Conditions requises : - Appareil Android 6.0 ou supérieur - Application JustRemotePhone installée - Les deux appareils sur le même réseau WiFi

    3.2 Installer l'Application de Jumelage¶

    1. Télécharger l'application
    2. Visitez : https://www.justremotephone.com/v6.10/CallCenter.msi

    3. Téléchargez et installez sur votre Windows

    4. Installer l'application Android

    5. Sur votre Android, recherchez "JustRemotePhone" sur Google Play

    6. Installez l'application

    7. Jumeler les appareils

    8. Ouvrez l'application sur Windows
    9. Ouvrez l'application sur Android
    10. Suivez les étapes de jumelage (un code sera affiché)
    📖 Guide Détaillé de Jumelage

    Pour des instructions étape par étape avec captures d'écran, consultez : App-Call-remote - Guide Complet

    3.3 Vérifier le Jumelage¶

    1. Effectuer un appel de test
    2. Appelez depuis votre Android vers n'importe quel numéro

    3. Centralite devrait détecter l'appel automatiquement

    4. Vérifier la notification

    5. Vous devriez voir une notification sur Windows : "📞 Appel détecté : +34 XXX XXX XXX"
    6. La fiche Teamleader devrait s'ouvrir automatiquement

    ✅ Jumelage Terminé

    Votre Centralite détecte maintenant automatiquement les appels depuis votre Android.

    Étape 4 : Enregistrer la Licence¶

    📝 Requis pour Usage Complet

    L'enregistrement est gratuit et nécessaire pour activer toutes les fonctionnalités.

    4.1 Formulaire d'Enregistrement¶

    1. Ouvrir le formulaire

    2. Visitez : https://forms.office.com/r/5k9k54cugV

    3. Remplir les données

    4. Nom complet
    5. Entreprise
    6. Email
    7. Nombre de licences nécessaires

    8. Cas d'usage

    9. Envoyer le formulaire

    10. Cliquez sur "Envoyer"
    11. Vous recevrez votre licence par email dans 24-48 heures

    4.2 Activer la Licence¶

    1. Ouvrir la configuration
    2. Clic droit sur l'icône de Centralite

    3. Sélectionner "Configuration"

    4. Onglet Licence

    5. Naviguez vers l'onglet "Licence"

    6. Collez la clé de licence reçue par email

    7. Activer

    8. Cliquez sur "Activer la licence"
    9. Vous verrez un message : "✅ Licence activée correctement"

    ✅ Enregistrement Terminé

    Votre Centralite est complètement enregistrée et prête à être utilisée.

    ✅ Vérification Finale¶

    Liste de Vérification d'Installation¶

    Avant de commencer à utiliser Centralite, vérifiez que toutes les étapes sont terminées :

    • Application installée (icône visible dans la barre des tâches)
    • API Teamleader configurée (identifiants OAuth2)
    • OpenRouter configuré (Clé API et modèle IA)
    • Jumelage Android terminé (optionnel mais recommandé)
    • Licence enregistrée et activée
    • Connexion internet stable

    Premier Appel de Test¶

    1. Effectuer un appel
    2. Appelez un numéro de test

    3. Ou recevez un appel sur votre Android

    4. Vérifier le comportement

    5. ✅ Centralite détecte l'appel
    6. ✅ La fiche Teamleader s'ouvre
    7. ✅ L'enregistrement démarre
    8. ✅ Une note est créée dans Teamleader après raccrocher

    🎉 Félicitations !

    Votre Centralite Teamleader est complètement configurée et prête à optimiser vos appels.
